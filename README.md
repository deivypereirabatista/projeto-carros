# Lista de Carros com Bootstrap

Projeto desenvolvido para estudar o **Bootstrap**. Foi o meu primeiro contato com a biblioteca e rendeu um grande aprendizado.

## Sobre o projeto

O sistema exibe uma lista de carros a partir de um **array pré-criado**. A maior parte da interação e da inclusão dos objetos na página é feita com **JavaScript**.

## Funcionalidades

- Listagem de carros em cards, gerados dinamicamente a partir de um array.
- Cada card possui um botão que abre um **modal** com as informações e a descrição somente daquele carro.
- Ao clicar em **Close**, o modal é fechado e o usuário volta para a página inicial.

## Tecnologias utilizadas

- HTML
- CSS
- JavaScript
- Bootstrap

## Aprendizados

- Primeiro contato com o Bootstrap e seus componentes (cards e modais).
- Renderização de elementos na página com JavaScript a partir de uma lista de objetos.
- Integração entre os componentes do Bootstrap e a lógica em JavaScript.

## Observações

Trata-se de um sistema simples, sem uma interface gráfica elaborada, mas que cumpriu seu objetivo: servir como base de estudo e aprendizado.
